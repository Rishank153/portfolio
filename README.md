# Rishank Rajput — Portfolio

Formal single-page portfolio (HTML, CSS, vanilla JavaScript).

## Preview

```bash
cd portfolio
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Customize

- Update `Rishank-Rajput-Resume.pdf` when your resume changes.
- Point the Task Manager GitHub link to the correct repo if you have one.

## Deploy

Host the `portfolio` folder on GitHub Pages, Netlify, or Vercel (static site).
